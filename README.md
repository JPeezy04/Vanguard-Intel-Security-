# Vangaurd Intel Security 
## Overivew 
Vangaurd Intel Security is a cybersecurity demonstration designed to protect oil inventory data through integrity validation, authentication, access control, and software supply chain security.
## Security Features
** Oil Data Validation: Checks oil inventory data to make sure required infomartion is present and valid
** SHA-256 Integrity Checking: Detects whether oil invenotry data has been changed  or tampered with.
** SBOM Scanning: Reviews software dependices to help identify components and potential supply chain secuirty risks.
** Vulnerability Detetction: Flags known vulnerable depenedinces to demonstrate software supply chain risks
** Authentication & Access Control: Requires valid user credntila and assigns roles to help prevcent unauthorized access.

## Demo Capabilities 
- Validate oil inventory data before processing.
- Detect unauthorized changes to oil inventory data using SHA-256 integrity checks.
- Scan software dependencies using an SBOM to identify potential security risks.
- Detect intentionally vulnerable dependencies to demonstrate software supply chain threats.
- Test successful and failed login attempts to demonsrate authentication and access control.
